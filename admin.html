이 페이지는 내 컴퓨터에서만 씁니다

맛집을 추가·수정하려면 내 컴퓨터에서 개발 서버를 켠 뒤 열어야 합니다. 지금은 저장할 곳을 찾지 못했습니다.

  1. PowerShell 을 열고 프로젝트 폴더로 이동합니다.
  2. npm run dev 를 칩니다.
  3. http://localhost:5173/admin.html 로 들어옵니다.

맛집 추가

태그 1개 이상

고른 태그가 카드 이름 오른쪽에 표시됩니다.

지금 카드에는 표시되지 않지만, 기록해두면 나중에 쓸 수 있습니다.

네이버지도 앱에서 가게 → 공유 → 링크 복사

구글지도에서 가게 → 공유 → 링크 복사. 좌표가 들어 있으면 아래 위도·경도를 자동으로 채웁니다.

구글지도(PC)에서 가게 위치를 마우스 오른쪽 클릭하면 맨 위에 33.44, 126.91 같은 숫자가 나옵니다. 그걸 눌러 복사한 뒤 아래 칸에 통째로 붙여넣어도 됩니다.

카드에 표시되지는 않지만 '가까운 순' 정렬에 쓰입니다. 비워두면 맨 뒤로 밀립니다.

등록된 맛집

고치려면 수정, 폐업했으면 삭제를 누르세요.

손님 화면에 올리기

여기서 저장한 내용은 아직 내 컴퓨터에만 있습니다. 실제 사이트에 반영하려면 PowerShell 에서 아래를 차례로 치세요. 

npm run check
git add -A
git commit -m "맛집 목록 갱신"
git push

올린 뒤 잠시 기다리면 손님 화면에 반영됩니다.
