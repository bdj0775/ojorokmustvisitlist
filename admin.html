인터넷에서 쓰려면 배포된 사이트 주소로 들어와야 하고, 내 컴퓨터에서 쓰려면 개발 서버를 켜야 합니다.

  1. PowerShell 을 열고 프로젝트 폴더로 이동합니다.

맛집 추가

태그 1개 이상

고른 태그가 카드 이름 오른쪽에 표시됩니다.

카드 오른쪽에 작게 표시됩니다. 예: 성산, 조천, 애월

네이버지도 앱에서 가게 → 공유 → 링크 복사

구글지도에서 가게 → 공유 → 링크 복사. 링크에 좌표가 들어 있으면 지도용 좌표도 자동으로 채워집니다.

비워두셔도 됩니다. 좌표가 있으면 '가까운 순' 정렬이 직선거리로 알아서 동작합니다.

지도에 핀 찍기 (선택 — 비워도 됩니다)

좌표를 넣은 곳만 지도에 표시됩니다. 나중에 채워도 되니 지금은 건너뛰셔도 됩니다.

구글지도(PC)에서 가게 위치를 마우스 오른쪽 클릭하면 맨 위에 33.44, 126.91 같은 숫자가 나옵니다. 그걸 눌러 복사한 뒤 아래 칸에 통째로 붙여넣으면 자동으로 나뉩니다.

영어 · 중국어 번역 (선택 — 비우면 한국어가 나옵니다)

비워두면 손님 화면에 한국어가 그대로 나오므로 사이트가 깨지지 않습니다. 상호명은 한글을 괄호로 남겨주세요 — 외국 손님이 택시 기사에게 보여주거나 간판을 찾을 때 필요합니다. (예: Namyang Susan (남양수산))
