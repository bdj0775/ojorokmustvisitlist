🔑 주인장 열쇠

맛집을 저장하려면 GitHub 열쇠(토큰)가 한 번 필요합니다. 이 열쇠는 이 브라우저에만 저장되고 사이트에는 올라가지 않습니다. 다른 사람 컴퓨터에서는 쓰지 마세요.

열쇠 만드는 법 (처음 한 번만)
  1. github.com/settings/personal-access-tokens/new 를 엽니다.
  2. Token name: 아무 이름 (예: 오조록 맛집 관리)
  3. Expiration: 원하는 기간 (1년 권장)
  4. Repository access: Only select repositories → ojorokmustvisitlist 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로
  6. Generate token → 나온 값을 복사해서 아래에 붙여넣기

⚠️ 반드시 이 저장소 하나만, Contents 권한만 주세요. 열쇠가 새어나가도 피해가 이 사이트 안에서 그치도록 하는 안전장치입니다.

구글지도(PC)에서 가게 위치를 마우스 오른쪽 클릭하면 맨 위에 33.44, 126.91 같은 숫자가 나옵니다. 그걸 눌러 복사한 뒤 아래 칸에 통째로 붙여넣어도 됩니다.
