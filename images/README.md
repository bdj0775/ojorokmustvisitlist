이 폴더에 장소 사진과 공유 미리보기 이미지를 넣습니다.

- **og.png** — 카톡·라인에 링크를 붙였을 때 뜨는 미리보기 그림 (1200x630).
  지금 것은 사진이 없어 사이트 색으로 급하게 만든 임시본입니다.
  실제 사진으로 바꾸려면 같은 이름·같은 크기로 덮어쓰면 됩니다.
  (파일 이름을 바꾸면 index.html 의 og:image 도 함께 고쳐야 합니다)

- **장소 사진** — 가로 1200px 정도로 줄여서 넣으면 로딩이 빠릅니다.
  places.json 의 "photo" 에 images/파일명.jpg 형태로 적으세요.
  지금 카드는 사진을 표시하지 않지만 값은 그대로 보관됩니다.
